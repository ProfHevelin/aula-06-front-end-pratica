# 🌐 Site Simples — HTML e CSS

Este repositório contém o código-fonte do **site simples desenvolvido durante a aula**, utilizando conceitos básicos de **HTML e CSS**.

A proposta é utilizar este projeto como uma base para **praticar, experimentar e testar novas ideias**.

## 🎯 Proposta da atividade

Esta é uma **atividade opcional** para quem deseja praticar um pouco mais os conteúdos trabalhados em aula.

Você pode baixar o projeto, fazer as alterações que quiser e testar diferentes possibilidades de **estruturação e estilização de páginas web**.

Não existe uma única forma correta de modificar o projeto. O objetivo é **experimentar e aprender na prática**.

## 💡 O que você pode modificar?

Algumas ideias para começar:

### HTML

* Alterar os textos e títulos da página;
* Adicionar novos parágrafos;
* Criar novas seções;
* Adicionar imagens;
* Criar listas;
* Adicionar links;
* Inserir botões;
* Organizar melhor o conteúdo utilizando elementos semânticos.

### CSS

* Alterar cores de fundo e textos;
* Modificar fontes e tamanhos;
* Ajustar margens e espaçamentos;
* Alterar bordas e arredondamentos;
* Modificar o tamanho das imagens;
* Centralizar e organizar elementos;
* Criar efeitos ao passar o mouse (`:hover`);
* Experimentar diferentes combinações de cores;
* Melhorar a aparência e organização da página.

## 🧪 Dicas para experimentar

Se não souber por onde começar, tente fazer pequenas alterações e observe o resultado.

**1. Comece pelas cores**

Experimente alterar o `background-color`, `color` e as cores das bordas.

**2. Brinque com os textos**

Teste diferentes valores de `font-size`, `font-family`, `font-weight` e `text-align`.

**3. Explore os espaçamentos**

Use `margin` e `padding` para perceber como eles alteram o espaço entre os elementos.

**4. Organize os elementos**

Experimente utilizar `display: flex` para organizar elementos lado a lado ou alinhar conteúdos.

**5. Teste o `:hover`**

Crie uma mudança visual quando o usuário passar o mouse sobre um botão ou link.

Exemplo:

```css
button:hover {
    background-color: #333;
    color: white;
}
```

**6. Faça uma alteração por vez**

Altere uma propriedade, salve o arquivo e atualize o navegador para observar o resultado. Assim, fica mais fácil entender o efeito de cada mudança.

**7. Quebre e conserte!**

Também faz parte do aprendizado testar algo que não funciona como esperado. Observe o resultado, identifique o problema e tente corrigir. 😉

## 📥 Como utilizar o projeto

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no seu editor de código.
3. Abra o arquivo HTML no navegador.
4. Faça as alterações desejadas.
5. Salve e atualize a página para visualizar os resultados.
6. Se quiser, publique sua versão em um novo repositório no GitHub.

## 📸 Compartilhe no fórum

Depois de realizar suas alterações, você pode compartilhar sua versão com a turma no **fórum da atividade**.

Você pode enviar:

* 📷 **Uma foto ou captura de tela** mostrando o resultado do seu site; ou
* 🔗 **O link do seu repositório no GitHub**, caso tenha publicado sua versão.

Se quiser, conte também **o que você modificou** ou qual recurso de HTML/CSS decidiu experimentar.

## ⭐ Lembre-se

Esta é uma **atividade opcional**. Você não precisa fazer todas as sugestões acima.

Escolha algumas alterações, teste suas ideias e aproveite o projeto para **praticar HTML e CSS de forma livre e criativa**.

O mais importante é **experimentar, observar os resultados e aprender com o processo! 🚀**
